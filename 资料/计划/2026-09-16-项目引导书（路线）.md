## 1. 项目是什么

**AI-ToRAG**：企业私有化知识库问答系统（RAG）。自然语言提问 → 检索企业自有知识 → 生成**带引用来源**的回答。全组件可私有化部署，数据不出内网。

```
离线：文档 ──上传→标准化→解析→向量化──▶ 向量知识库
在线：问题 ──向量化→向量召回→Rerank→生成回答（仅依据离线知识，可溯源）
```

核心原则（按优先级）：**答案可信 > 简单可维护 > 中文优先 > 可评估**。

## 4. 新人上手（30 分钟路径）

```bash
# 1) 环境：Python ≥ 3.11 + Podman ≥ 4.7
python -m venv .venv && .venv/Scripts/pip install -e .

# 2) 起依赖（postgres / redis / minio / milvus）
podman compose -f deploy/podman-compose.dev.yml up -d

# 3) 配置与建表（默认 fake 模型，零外部依赖）
cp .env.example .env
.venv/Scripts/python -c "from infra.pg import init_db; init_db()"

# 4) 起 API 与 worker（两个终端）
.venv/Scripts/python -m uvicorn services.api.main:app --reload
.venv/Scripts/python -m services.worker
```

体验路径：`http://localhost:8000/` → 建知识库 → 上传文档 → 等状态「就绪」→ 提问看引用卡片。

接真实模型：`.env` 中 `EMBED/RERANK/LLM_PROVIDER` 改 `openai` + 填地址（vLLM/TEI 等 OpenAI 兼容服务均可）。验证：`.venv/Scripts/python -m pytest`。

## 6. 开发约定（红线）

1. 模型三角色只能经 `services.model_gateway.get_gateway()` 访问，业务代码不得直连模型服务；
2. 权限过滤必须在召回期下推，**绝不能检索后再过滤**；
3. PG 是元数据唯一事实源，Milvus 删改以 PG 为准；
4. 所有测试必须零外部依赖可跑（fake 网关 + sqlite）；
5. 全部写操作幂等；SSE 流必须以 `refs` 事件结束。

## 7. 风险提示（持续关注）
